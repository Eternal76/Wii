# Тренажёр по информатике — задание 24 ЕГЭ

Интерактивный статический тренажёр для подготовки к заданию 24 ЕГЭ по информатике.
Тренажёр состоит из пяти последовательных этапов: следующий открывается после
прохождения предыдущего.

## Этапы

1. **Синтаксис** — вопросы с выбором ответа, вывод кода и сопоставление; мгновенная
   обратная связь с педагогическими подсказками.
2. **Анимация** — пошаговое выполнение программы: подсветка текущей строки, таблица
   значений переменных и пояснения.
3. **Сборщик** — сборка программы из блоков кода с помощью drag-and-drop.
4. **Отладчик** — поиск и исправление ошибок в коде с запуском Python в браузере.
5. **Самостоятельное написание** — решение задачи с нуля и проверка на двух тестах
   (маленьком и большом), затем рефлексия.

Прогресс сохраняется в `localStorage` (ключ `ege24_trainer_progress`).

## Технологии

- HTML5, CSS3
- Чистый JavaScript (без сборщиков и ES-модулей)
- [Pyodide](https://pyodide.org/) — запуск Python прямо в браузере
- [CodeMirror 5](https://codemirror.net/5/) — редактор кода с подсветкой синтаксиса
- [SortableJS](https://sortablejs.github.io/Sortable/) — drag-and-drop на этапе 3


## Запуск локально

Проект статический, но страницы загружают данные через `fetch()`, поэтому открывать
файлы напрямую как `file://` нельзя — браузер заблокирует такие запросы. Нужен
локальный веб-сервер.

Вариант с Python:

```bash
python -m http.server 8000
```

Вариант с Node.js:

```bash
npx serve
```

После запуска откройте в браузере <http://localhost:8000/index.html>.

Первое открытие этапов 4 и 5 может занять несколько секунд: Pyodide подгружает
WASM-рантайм Python с CDN, до готовности показывается сообщение «Загрузка Python...».
Для работы этих этапов требуется подключение к интернету (CDN Pyodide, CodeMirror,
SortableJS).

## Публикация на GitHub Pages

Все пути к стилям, скриптам и JSON-файлам относительные, поэтому проект можно
публиковать как есть: в настройках репозитория включите GitHub Pages и укажите
ветку (например, `main`) и корневую папку (`/`).
