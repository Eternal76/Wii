# План контента

Тренажёр состоит из пяти последовательных этапов.

| № | Название |
|---|---------------------------|
| 1 | Синтаксис |
| 2 | Анимация |
| 3 | Сборщик |
| 4 | Отладчик |
| 5 | Самостоятельное написание |

## Правило открытия этапов

Каждый следующий этап открывается только после **80%** правильных ответов на предыдущем.

Этап 1 доступен сразу. Этапы 2–5 остаются закрытыми, пока порог 80% на предыдущем этапе не выполнен.
