# Архитектура тренажёра ЕГЭ (задание 24)

## Стек

- **HTML5** — разметка страниц.
- **CSS3** — оформление.
- **ES6+** — клиентская логика без сборщиков и без Node.js.
- **Pyodide** (CDN) — только для этапов 4 и 5 (выполнение Python в браузере).
- **CodeMirror 5** — редактор кода.
- **SortableJS** — только для этапа 3 (перестановка фрагментов).

Все библиотеки подключаются с CDN. Серверной части нет: статический сайт.

## Структура папок

```
/
├── architecture.md
├── content-plan.md
├── css/          # стили
├── js/           # скрипты
├── data/         # контент заданий (JSON)
└── files/        # вспомогательные файлы (примеры, вложения)
```

## Данные и прогресс

- Весь учебный контент (задания, тексты, варианты ответов, эталоны) хранится в JSON-файлах в каталоге `data/`.
- Прогресс пользователя сохраняется в `localStorage` под ключом `ege24_trainer_progress`.
